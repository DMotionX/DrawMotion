## 3. Privacy Policy (Strictly Local-First)

Your creative work, privacy, and sovereignty are paramount. DrawMotion is designed from the ground up with a strict **Local-First** philosophy.

### 3.1 Zero Data Harvesting
We do **not** collect, harvest, monitor, sell, or profile your personal information, project files, artistic canvas data, or system telemetry. There are no background analytics, trackers, or behavioral telemetry embedded in the software.

### 3.2 100% Offline Capable
DrawMotion functions fully without an active internet connection. Your canvas drawings, timeline configurations, audio voiceovers, and rendered videos are processed and stored strictly on your local disk. We have zero access to your projects.

### 3.3 Network Communication (Updates Only)
The only automated network communication performed by DrawMotion occurs during software update checks:
- When checking for updates, DrawMotion makes a secure HTTP GET request to our official GitHub Releases API or hosting endpoint to retrieve the latest version tag and release changelog.
- Standard hosting providers (such as GitHub or Vercel) automatically process technical routing metadata (including incoming IP addresses, HTTP User-Agent strings, and application version headers) as required for operational routing and DDoS mitigation.
- We do not link this network metadata to your personal identity, nor do we retain, sell, or disclose it for marketing or advertising purposes.

### 3.4 Support Communications
If you voluntarily contact us via email ([easysoft.dv2team@gmail.com](mailto:easysoft.dv2team@gmail.com)) or send bug logs and screenshots, we receive only the technical details you choose to share. This information is used strictly and exclusively to diagnose bugs and provide technical assistance.

### 3.5 Web Presence
Our companion web presence ([https://drawmotion-web.vercel.app/](https://drawmotion-web.vercel.app/)) operates as an information and documentation portal and does not utilize intrusive behavioral tracking cookies or third-party advertising trackers.
